## 第一部分 · 模组实现了什么功能

### 1.1 定位

**ICU** —— 在 Minecraft 中还原真实的「身体损伤 + 医疗体系」。
玩法以**独立模块**形式添加，一个功能一个包。

| 模块 | 包 | 说明 |
|---|---|---|
| 大出血 | `gameplay.bleeding` | 失血、绷带治疗、恢复期 |
| 血容量 | `gameplay.blood` | 隐藏血量资源，出血时归零即死 |
| 疼痛值 | `gameplay.pain` | 出血与崴脚共用的疼痛计量 |
| 摔落崴脚 | `gameplay.sprain` | 摔落造成的脚踝扭伤 |
| 绷带 | `item` | 治疗大出血的唯一手段 |
| JEI 集成（可选） | `compat.jei` | 绷带信息页 + ICU「大出血流程」分类页 |

> **心跳音效尚未实现**：设计已定稿，等音频素材（由项目所有者提供）。

### 1.2 大出血

| # | 行为 | 精确实现 |
|---|---|---|
| 1 | **触发条件** | 被剑/斧类武器命中，且**护甲+附魔结算后**最终伤害 **> 7 点** |
| 2 | **层数叠加** | 每次命中 **+1 层**，**无上限** |
| 3 | **失血** | 大出血期间血容量 **每秒 −5%** |
| 4 | **致死** | **只有血容量归零会致死**。旧的「每秒扣健康」伤害已删除，血容量是唯一真相 |
| 5 | **强制趴下** | `SWIMMING` 姿态 + 水平速度清零 + 禁跳 |
| 6 | **锁击退** | `push(0,0,0)` |
| 7 | **附加效果** | 反胃 `CONFUSION` + 黑暗 `DARKNESS`，每 tick 刷新 |
| 8 | **视觉** | 血粒子，数量随层数增加 |
| 9 | **死亡消息** | 「XXX 血容量归零，失血过多而亡」 |
| 10 | **结束** | 绷带治疗，或死亡重生 |

> ⚠️ **阈值 7 的实测影响**：护甲减免后极难达到。
> 无甲需原始伤害 7；皮革约 15；铁甲约 18.5；**钻石甲约 28**（游戏内最高约 19.5）。
> 即**穿铁甲以上几乎不会出血**。这是项目所有者明确选定的数值。

### 1.3 血容量

| 规则 | 数值 |
|---|---|
| 初始 / 上限 | 100% |
| 大出血期间 | 每秒 **−5%**（100% → 0% = 20 秒）|
| 归零 | **立即死亡**，无论剩余生命值多少 |
| 自然恢复 | **非出血期间**每 **10 分钟 +5%**，上限 100% |
| 绷带治疗 | **不重置**，保留当前数值 |
| 再次出血 | 从当前数值**继续**下降 |
| 死亡重生 | 重置为 100% |

### 1.4 绷带

| 项 | 值 |
|---|---|
| 配方 | **3 纸 + 1 线 + 1 羊毛** |
| 堆叠 | 上限 16，使用消耗 1 个 |
| 使用方式 | 右键**持续按住** 3 秒 |
| 期间 | 大出血照常生效，血容量继续每秒 −5% |
| 成功 | 解除大出血、保留血容量、进入恢复期 |
| 失败 | 3 秒内血容量归零 → 死亡 |

### 1.5 疼痛值（出血与崴脚共用）

| 来源 | 每秒变化 |
|---|---|
| 大出血 | **+10%**（即使静止不动也生效）|
| 崴脚·行走 | **+5%** |
| 崴脚·奔跑 | **+10%** |
| 崴脚·跳跃一次 | **+15%**（一次性）|
| 趴下（倒地）状态 | **−5%** |

| 阈值行为 | 说明 |
|---|---|
| 达到 **100%** | 强制趴下无法行动；聊天框**连续弹 3 次**「我好疼 我好疼」（**仅自己可见**）|
| 降至 **80%** | 立即恢复行动，疼痛从 80% 继续计算 |
| 大出血未解除时 | +10% 与 −5% 同时生效 → 净 +5% → **卡在 100%** 直到出血解除 |

### 1.6 大出血恢复期

| 规则 | 值 |
|---|---|
| 时长 | **5 分钟** |
| 复发条件① | 奔跑**连续超过 15 秒** |
| 复发条件② | **第 4 次跳跃** |
| 复发后果 | 重新出血（血容量**不重置**）+ 疼痛每秒 +10% |
| 计时重置 | 期间**任何**跳跃或奔跑都重置 5 分钟计时（未达阈值则不复发）|
| 结束 | 保持不跑不跳满 5 分钟 → 恢复完成 |

### 1.7 摔落崴脚

| 摔落高度（原版 `fallDistance`）| 触发概率 |
|---|---|
| ≤ 5 格 | 不触发 |
| > 5 且 < 10 | **35%** |
| ≥ 10 且 < 15 | **50%** |
| ≥ 15 且 < 20 | **90%** |
| ≥ 20 | **100%** |

| 修正 | 效果 |
|---|---|
| 落点为**干草块** | 概率 **−20 个百分点**（35%→15% 等），最低 0%（**是减概率，不是豁免**）|
| 保护 / 摔落保护附魔 | **每级 −8 个百分点**；两者同时存在取**较高等级** |
| 附魔达到 **5 级** | **完全免除** |

**自动豁免**：落入水中（含仅 1 格）、缓降药水、鞘翅滑翔、紫颂果传送、抗火状态，以及原版已豁免的情况。

**提示**：触发时弹出 1 次「完了 我崴到脚了」（**仅自己可见**）。

### 1.8 明确**不做**的功能

止血物品以外的治疗手段、医疗方块、感染系统、骨折、内脏损伤、GUI、指令、HUD 提示、成就。
**心跳音效**：设计已定，等素材。

### 2.3 变更分类总账

#### A. 命名统一（解决「鸡同鸭讲」）

| 项 | 改前 | 改后 |
|---|---|---|
| mod id / 包 / 主类 | `nofo` / `com.nofo.nofo` / `NofoMod` | **`icu` / `com.icu.icu` / `IcuMod`** |
| 附件类 / 玩法包 | `ModAttachments` / `bleed/` | **`IcuAttachments` / `gameplay/bleeding/`** |
| 逻辑类 / 伤害类 / 数据类 | `BleedHandler` / `BleedDamage` / 内嵌 | **`BleedingFeature` / `BleedingDamage` / `BleedingData`** |
| 资源目录 / 注册 id | `assets/nofo/` / `nofo:bleed` | **`assets/icu/` / `icu:bleed`** |
| 本地目录 | `nofo1.21.1` | **`icu`** |

#### B. 结构重组（为可持续维护）

```
src/main/java/com/icu/icu/
├── IcuMod.java              入口，只做注册
├── IcuAttachments.java      全部持久化数据的唯一注册点
├── IcuItems.java            物品注册
├── item/BandageItem.java    绷带
└── gameplay/                ★ 一个功能一个子包
    ├── bleeding/            出血 + 恢复期
    ├── blood/               血容量
    ├── pain/                疼痛值
    └── sprain/              摔落崴脚
```

#### C. 功能修正

| 项 | 改前 | 改后 | 原因 |
|---|---|---|---|
| 触发阈值 | 10 | 3（v0.0.2）| 10 在护甲减免后**永远达不到** |
| 触发阈值 | 3 | **7**（v0.1.0）| 项目所有者要求取高值 |
| 致死机制 | 每秒扣健康 + 血容量 | **仅血容量归零** | 避免两套机制抢戏，血容量成为唯一真相 |

#### D. 构建与发布

| 项 | 改前 | 改后 |
|---|---|---|
| 构建位置 | 本机（内存不足必失败）| **GitHub Actions 云端** |
| 触发 | 手动 | **推 `v*` 标签自动发布**；推 main 自动编译检查 |
| 产物名 | `icu-0.0.1.jar` | **`icu-Mod-<版本>.jar`** |
| 源码分发 | `-sources.jar`（**会被误装成模组**）| **`icu-<版本>-src.zip`** |
| 失败可见性 | 需翻 Actions 页 | **CI 自动写 `BUILD_FAILURES.md`** |

#### E. 合规与文档

| 项 | 内容 |
|---|---|
| 许可证 | 三处统一 **Apache-2.0** |
| 文档 | `README.md`、`docs/DEVELOPMENT.md`、`docs/PROJECT_REPORT.md`、`docs/CHANGELOG.md` |
| 修正 | 修掉 2 处断链；版本号全项目同步 |

### 2.5 排查方法留档

**「装了却没反应」** 看日志三处：

| 观察点 | 正常 | 异常 |
|---|---|---|
| `Found mod file "..."` | `icu-Mod-<版本>.jar` | `icu-<版本>-sources.jar` |
| `[ICU] loaded` | 出现 1 次 | **0 次** |
| `@EventBusSubscriber ... for icu` | 之后有注册记录 | **无后续** |

**编译错误**：看 `BUILD_FAILURES.md`，或 Actions 页对应 run 的 Build 步骤。
